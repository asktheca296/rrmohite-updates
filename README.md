# rrmohite-updates

Official notifications and circulars from the Income Tax Department (e-filing portal "Latest News") and the Reserve Bank of India (notifications feed), collected every three hours by `fetch.mjs` on GitHub Actions.

`updates.json` is read by https://rrmohite.in/regulatory-updates. Each entry keeps the regulator's own wording and a link to the official document. Nothing here is reviewed or interpreted.

If a source stops working, the scheduled run fails and GitHub emails the account owner.
